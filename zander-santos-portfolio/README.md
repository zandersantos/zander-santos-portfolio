## Getting Started

### Prerequisites

- Node.js 18.x or higher
- npm

### Installation

```bash
git clone https://github.com/zandersantos/zander-santos-portfolio.git
cd zander-santos-portfolio
npm install
npm run dev
# visit http://localhost:3000
```
